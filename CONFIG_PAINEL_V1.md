# Painel de Configuração V1

A Nina agora possui um painel interativo aberto por `/config`.

## Categorias
- Geral
- AutoMod
- Boas-vindas
- Tickets
- Logs
- Autoroles

## V1
- Navegação por select menu.
- Botão voltar/fechar/atualizar.
- Toggles para economia, moderação, level-up, AutoMod, boas-vindas e tickets.
- Seleção de canal para boas-vindas, tickets e logs.
- Seleção de cargo de suporte para tickets.
- Configuração rápida de spam, anti-raid e Anti-Scam visual via modais.
- Edição rápida dos textos de boas-vindas.
- Ativação/desativação de categorias de logs.
- Resumo do estado dos sistemas na tela inicial.

Os comandos antigos continuam funcionando para compatibilidade durante a migração. A ideia das próximas versões é migrar gradualmente as configurações avançadas para os painéis.
